# SECTION B - API Endpoint Plan

**Roles used in the table:**

| Role        | Meaning                                                   |
| ----------- | --------------------------------------------------------- |
| None        | Anybody can call it, no login needed                      |
| Any         | The user must be logged in, it does not matter which role |
| Organiser   | Only a logged in user with the Organiser role             |
| Participant | Only a logged in user with the Participant role           |

---

## 1. Authentication

| HTTP Method | Route              | Description                                                           | Role Required | Request Body                                                                 | Expected Response                                                                                                                                             |
| ----------- | ------------------ | --------------------------------------------------------------------- | ------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST        | /api/auth/register | Creates a new account and saves the user with the role the user picks | None          | { firstName, lastName, email, password, phoneNumber, dateOfBirth, roleName } | 201 Created - the new user id and email<br><br>400 Bad Request - a field is missing or the email is not valid<br><br>409 Conflict - the email is already used |
| POST        | /api/auth/login    | Checks the email and password and gives back a JWT token              | None          | { email, password }                                                          | 200 OK - token, userId and roleName<br><br>400 Bad Request - email or password not sent<br><br>401 Unauthorized - wrong email or password                     |

## 2. User Profile

| HTTP Method | Route           | Description                                                                           | Role Required | Request Body                                      | Expected Response                                                                                                              |
| ----------- | --------------- | ------------------------------------------------------------------------------------- | ------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| GET         | /api/users/me   | Gets the profile of the user that is logged in, it’s used to show the profile page    | Any           | None                                              | 200 OK - the user profile without the password<br><br>401 Unauthorized - not logged in                                         |
| PUT         | /api/users/me   | Updates the profile details of the user that’s logged in                              | Any           | { firstName, lastName, phoneNumber, dateOfBirth } | 200 OK - the updated profile<br><br>400 Bad Request - a field is not valid<br><br>401 Unauthorized - not logged in             |
| GET         | /api/users/{id} | Gets a user. The organiser uses it to see the details of a participant in their event | Organiser     | None                                              | 200 OK - the user profile<br><br>403 Forbidden - the caller is not an organiser<br><br>404 Not Found - the user does not exist |

## 3. Events

| HTTP Method | Route                 | Description                                                                                  | Role Required | Request Body                                                                         | Expected Response                                                                                                                                                                      |
| ----------- | --------------------- | -------------------------------------------------------------------------------------------- | ------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET         | /api/events           | Gets all the events so that participants can browse them                                     | None          | None                                                                                 | 200 OK - a list of events                                                                                                                                                              |
| GET         | /api/events/{id}      | Gets one event with its details, and the latitude and longitude that is used for the weather | None          | None                                                                                 | 200 OK - the event<br><br>404 Not Found - the event does not exist                                                                                                                     |
| GET         | /api/events/my-events | Gets only the events that the user that logged in as the organiser created                   | Organiser     | None                                                                                 | 200 OK - a list of the organiser's events<br><br>401 Unauthorized - not logged in<br><br>403 Forbidden - the caller is not an organiser                                                |
| POST        | /api/events           | Makes a new event. The organiser ID is taken from the token, not from the body               | Organiser     | { name, description, eventDate, location, province, eventType, latitude, longitude } | 201 Created - the new event with its id<br><br>400 Bad Request - a field is missing or the date is in the past<br><br>403 Forbidden - the caller is not an organiser                   |
| PUT         | /api/events/{id}      | Updates an event. An organiser may only update their own event                               | Organiser     | { name, description, eventDate, location, province, eventType, latitude, longitude } | 200 OK - the updated event<br><br>400 Bad Request - a field is not valid<br><br>403 Forbidden - the event belongs to another organiser<br><br>404 Not Found - the event does not exist |
| DELETE      | /api/events/{id}      | Deletes an event and its categories, as an organiser may only delete their own event         | Organiser     | None                                                                                 | 204 No Content - the event was deleted<br><br>403 Forbidden - the event belongs to another organiser<br><br>404 Not Found - the event does not exist                                   |

## 4. Categories

| HTTP Method | Route                            | Description                                                                      | Role Required | Request Body                                               | Expected Response                                                                                                                                                                                                                                                                |
| ----------- | -------------------------------- | -------------------------------------------------------------------------------- | ------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET         | /api/events/{eventId}/categories | Gets all the categories of one event so that the participant can pick a distance | None          | None                                                       | 200 OK - a list of categories<br><br>404 Not Found - the event does not exist                                                                                                                                                                                                    |
| GET         | /api/categories/{id}             | Gets one category with its distance, fee and start time                          | None          | None                                                       | 200 OK - the category<br><br>404 Not Found - the category does not exist                                                                                                                                                                                                         |
| POST        | /api/events/{eventId}/categories | Adds a new category to an event, for example a 10km                              | Organiser     | { name, distanceKm, entryFee, maxParticipants, startTime } | 201 Created - the new category<br><br>400 Bad Request - the distance or the fee is not valid<br><br>403 Forbidden - the event belongs to another organiser<br><br>404 Not Found - the event does not exist<br><br>409 Conflict - the event already has a category with that name |
| PUT         | /api/categories/{id}             | Updates a category of an event                                                   | Organiser     | { name, distanceKm, entryFee, maxParticipants, startTime } | 200 OK - the updated category<br><br>400 Bad Request - a field is not valid<br><br>403 Forbidden - the category belongs to another organiser<br><br>404 Not Found - the category does not exist                                                                                  |
| DELETE      | /api/categories/{id}             | Deletes a category from an event                                                 | Organiser     | None                                                       | 204 No Content - the category was deleted<br><br>403 Forbidden - the category belongs to another organiser<br><br>404 Not Found - the category does not exist<br><br>409 Conflict - participants are already entered in this category                                            |

## 5. Event Enrolments

| HTTP Method | Route                            | Description                                                                                     | Role Required | Request Body   | Expected Response                                                                                                                                                                                                                                                                             |
| ----------- | -------------------------------- | ----------------------------------------------------------------------------------------------- | ------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST        | /api/enrolments                  | Enters the logged in participant into a category of an event and gives them a race number       | Participant   | { categoryId } | 201 Created - the enrolment with the race number<br><br>400 Bad Request - the category id is missing<br><br>403 Forbidden - the caller is not a participant<br><br>404 Not Found - the category does not exist<br><br>409 Conflict - already entered in this category or the category is full |
| GET         | /api/enrolments/me               | Gets all the enrolments of the logged in participant so they can see the events they entered in | Participant   | None           | 200 OK - a list of enrolments with the event and category<br><br>401 Unauthorized - not logged in                                                                                                                                                                                             |
| GET         | /api/enrolments/{id}             | Gets one enrolment and the participant who owns it or the organiser of the event may see it     | Any           | None           | 200 OK - the enrolment<br><br>403 Forbidden - the enrolment belongs to another user<br><br>404 Not Found - the enrolment does not exist                                                                                                                                                       |
| DELETE      | /api/enrolments/{id}             | Cancels an enrolment and only the participant who made it may cancel it                         | Participant   | None           | 204 No Content - the enrolment was cancelled<br><br>403 Forbidden - the enrolment belongs to another participant<br><br>404 Not Found - the enrolment does not exist<br><br>409 Conflict - the event is already finished                                                                      |
| GET         | /api/events/{eventId}/enrolments | Gets all the participants that entered an event and the organiser uses it for the start list    | Organiser     | None           | 200 OK - a list of enrolments with the participant names<br><br>403 Forbidden - the event belongs to another organiser<br><br>404 Not Found - the event does not exist                                                                                                                        |

## 6. Results

| HTTP Method | Route                         | Description                                                                                            | Role Required | Request Body                                         | Expected Response                                                                                                                                                                                                                                              |
| ----------- | ----------------------------- | ------------------------------------------------------------------------------------------------------ | ------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST        | /api/results                  | Captures the result of one enrolment after the race                                                    | Organiser     | { enrolmentId, finishTime, positionOverall, status } | 201 Created - the new result. 400 Bad Request - the finish time is not valid<br><br>403 Forbidden - the enrolment is not in the organiser's event<br><br>404 Not Found - the enrolment does not exist<br><br>409 Conflict - the enrolment already has a result |
| PUT         | /api/results/{id}             | Updates a result that was captured wrong                                                               | Organiser     | { finishTime, positionOverall, status }              | 200 OK - the updated result<br><br>400 Bad Request - a field is not valid<br><br>403 Forbidden - the result is not in the organiser's event<br><br>404 Not Found - the result does not exist                                                                   |
| DELETE      | /api/results/{id}             | Deletes a result that was captured by mistake                                                          | Organiser     | None                                                 | 204 No Content - the result was deleted<br><br>403 Forbidden - the result is not in the organiser's event<br><br>404 Not Found - the result does not exist                                                                                                     |
| GET         | /api/results/me               | Gets all the results of the logged in participant and this would be their personal performance history | Participant   | None                                                 | 200 OK - a list of results with the event, category and finish time<br><br>401 Unauthorized - not logged in                                                                                                                                                    |
| GET         | /api/events/{eventId}/results | Gets the result list of an event so that anybody can see who won                                       | None          | None                                                 | 200 OK - a list of results in position order<br><br>404 Not Found - the event does not exist                                                                                                                                                                   |
